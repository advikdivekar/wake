# The Last Satellite: Mission Memory Engine

> *Its mission ended. Its memories did not.*

OPS-SAT was ESA's flying laboratory, a CubeSat that re-entered the atmosphere on **22 May 2024**. This project is an **archival** analysis system built on its real, public telemetry and documents. It has two halves:

- **Telemetry Analyser (TabPFN).** For each archived telemetry segment it estimates P(anomalous), explains which measured characteristics drive the estimate, and ranks segments in an investigation queue.
- **Mission Memory Interpreter (Qwen3-8B + LoRA fine-tuned on Tinker).** It turns public mission documents into structured, source-linked records. It keeps *what is known* separate from *what is not*, and it never invents a root cause.

An evidence layer joins the two into **investigation cards**. Every statement on a card is either *measured* or *cited*, and an analyst can confirm, reject or investigate it.

> Nothing here is live. All numbers below are produced by scripts in this repo and stored in [`evaluations/`](evaluations/). The README is generated by `make post` from those files.

## Results

### Telemetry Analyser vs the published OPSSAT-AD benchmark (official test split, 529 segments, single logged run)

| Model | AUCPR | F1 | MCC |
|---|---|---|---|
| **TabPFN-v2 + selected features** (ours) | **0.996** (95% CI 0.989–1.000) | **0.982** (0.963–0.996) | **0.977** |
| TabPFN-v2, only the 18 published features (ours, like-for-like) | 0.989 | 0.950 | 0.937 |
| Random Forest, same selected features (ours) | 0.994 | 0.973 | 0.966 |
| XGBoost, same selected features (ours) | 0.993 | 0.968 | 0.960 |
| Isolation Forest, unsupervised (ours) | 0.401 | 0.499 | 0.362 |
| FCNN, best published (Ruszczak et al., *Sci Data* 2025) | 0.979 | 0.946 | 0.932 |

- **Errors.** The final model made 1 false alert(s) and missed 3 anomalies out of 529. Brier score 0.007.
- **Comparison with the tree models.** On our engineered features, TabPFN vs Random Forest is a statistical tie (McNemar p = 0.625).
- **Comparison on the paper's own 18 features.** With no feature engineering, TabPFN reaches AUCPR 0.989, while Random Forest reaches 0.970.

Full tables: [`evaluations/ours_vs_published.md`](evaluations/ours_vs_published.md) and [`evaluations/published_benchmark.md`](evaluations/published_benchmark.md).

### Mission Memory Interpreter: base Qwen3-8B vs fine-tuned (held-out documents, same prompt, same validator)

| Task | Base | Fine-tuned | Paired exact McNemar p |
|---|---|---|---|
| A. Structured record extraction (field-level exact match) | 0.722 | **0.863** (95% CI 0.832–0.888) | 5.77e-16 |
| B. Timeline: event dates vs publication date | 0.375 | 0.542 | 0.125 |
| C. Terminology with correct citation / "not in archive" | 0.962 | 0.827 | 0.0156 |
| D. Investigation note passes all checks | 0.560 | 1.000 | 0.000977 |

Task A details for the fine-tuned model:
- Valid schema: 1.000
- Evidence verbatim in source: 1.000
- Unsupported root causes: 0
- Whole-record exact match: 0.444

Total Tinker spend (estimated from token counts × list price): **$0.83**. The learning curve is in [`evaluations/tinker_learning_curve.json`](evaluations/tinker_learning_curve.json).

**The 95% target was not reached on test.** The fine-tuned model scores 0.863 on held-out test documents, against 0.930 on validation. Task C (terminology citations) **regressed** after fine-tuning.

**Training ran on Tinker's hosted service. Inference runs locally.** Tinker does not allow sampler checkpoints to be downloaded, and the evaluated run only saved those. The offline adapter is therefore the 200-example configuration, retrained with a downloadable checkpoint; its validation score is 0.923, against 0.930 for the final model. llama.cpp loads the Q4_K_M base plus this adapter converted to GGUF, with no Tinker key present. On held-out validation passages it scores 0.925 field exact match and agrees with the same adapter's full-precision Tinker outputs on 1.000 of fields.

## The console

`web/` contains a cinematic, single-scroll console built with Vite, React, react-three-fiber (a shader-lit Earth and a decaying CubeSat orbit), Lenis and Framer Motion. It has seven sections:

1. Elegy: the verified "last transmission" timeline.
2. Signal Observatory.
3. *The signal that should not be there*: a guided demo with a hidden label and a reveal.
4. Investigation Queue, with Confirm / Reject / Investigate.
5. Mission Memory: Q&A and extraction.
6. Model Laboratory: every chart is read from `evaluations/`.
7. Ofrenda: the export page.

When `make api` is running, the console talks to the live backend. Otherwise it falls back to a labelled **archived snapshot of real API responses** (`make snapshot`).

```bash
make api            # backend on :8000 (optional; enables live mode, feedback, free-form Q&A, export)
make llm            # local interpreter on :8081 (llama.cpp + adapter; optional)
make web            # console on :5173
```

## Run it

```bash
make setup                 # Python 3.11 venv + dependencies (uv)
make data features db      # download OPSSAT-AD (md5-verified), reproduce the 18 features, build SQLite
make docs-ingest           # fetch public documents (licence-aware), chunk, index (FTS5 + vectors)
make tabpfn-cv             # CV on the training split only
python -m training.tabpfn.threshold
make tabpfn-test           # ONE guarded run on the official test split
make app                   # API :8000 + console + local LLM :8081 (if models/adapter.gguf exists)
make test                  # unit + API tests
```

The Tinker steps (`make tinker-data tinker-train tinker-eval adapter offline`) need `TINKER_API_KEY` in `.env` and are guarded by `TINKER_BUDGET_USD`.

## Data, licences and honesty

- **Telemetry.** OPSSAT-AD (Zenodo 10.5281/zenodo.12588359), **CC-BY-4.0**. Our checks found 2123 segments, 303,493 points, 1594 train and 529 test segments, and an anomaly rate of 20.4%.
- **Paper discrepancy.** The paper's text says 1,494 training segments; its own table and the data say 1,594.
- **Feature reproduction.** Our port of the published feature code reproduces 16/18 features exactly (99.97% of values overall).
- **TabPFN.** All reported results use the **TabPFN v2** weights (Prior Labs License: Apache-2.0 + attribution). Newer TabPFN weights are non-commercial and were not used. *Built with TabPFN.*
- **Documents.** Full text is stored only where the licence allows (CC-BY, CC-BY-SA, MIT). Otherwise we store short excerpts and a link. See [`docs/provenance.csv`](docs/provenance.csv) and [`docs/licensing.md`](docs/licensing.md).
- **Limitations.** See [`docs/limitations.md`](docs/limitations.md).
