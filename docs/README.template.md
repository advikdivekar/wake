# The Last Satellite: Mission Memory Engine

> *Its mission ended. Its memories did not.*

OPS-SAT was ESA's flying laboratory, a CubeSat that re-entered the atmosphere on **22 May 2024**. This project is an **archival** analysis system built on its real, public telemetry and documents. It has two halves:

- **Telemetry Analyser (TabPFN).** For each archived telemetry segment it estimates P(anomalous), explains which measured characteristics drive the estimate, and ranks segments in an investigation queue.
- **Mission Memory Interpreter (Qwen3-8B + LoRA fine-tuned on Tinker).** It turns public mission documents into structured, source-linked records. It keeps *what is known* separate from *what is not*, and it never invents a root cause.

An evidence layer joins the two into **investigation cards**. Every statement on a card is either *measured* or *cited*, and an analyst can confirm, reject or investigate it.

> Nothing here is live. All numbers below are produced by scripts in this repo and stored in [`evaluations/`](evaluations/). The README is generated by `make post` from those files.

## Run it

```bash
make setup                 # Python 3.11 venv + dependencies (uv)
make data features db      # download OPSSAT-AD (md5-verified), reproduce the 18 features, build SQLite
make docs-ingest           # fetch public documents (licence-aware), chunk, index (FTS5 + vectors)
make tabpfn-cv             # CV on the training split only
python -m training.tabpfn.threshold
make tabpfn-test           # ONE guarded run on the official test split
make app                   # API :8000 + console + local LLM :8081 (if models/adapter.gguf exists)
make test                  # unit + API tests
```

The Tinker steps (`make tinker-data tinker-train tinker-eval adapter offline`) need `TINKER_API_KEY` in `.env` and are guarded by `TINKER_BUDGET_USD`.

## Data, licences and honesty

- **Telemetry.** OPSSAT-AD (Zenodo 10.5281/zenodo.12588359), **CC-BY-4.0**. Our checks found {{data.segments}} segments, {{data.points}} points, {{data.train}} train and {{data.test}} test segments, and an anomaly rate of {{data.anomaly_rate}}.
- **Paper discrepancy.** The paper's text says 1,494 training segments; its own table and the data say 1,594.
- **Feature reproduction.** Our port of the published feature code reproduces {{feat.exact_count}}/18 features exactly ({{feat.overall}} of values overall).
- **TabPFN.** All reported results use the **TabPFN v2** weights (Prior Labs License: Apache-2.0 + attribution). Newer TabPFN weights are non-commercial and were not used. *Built with TabPFN.*
- **Documents.** Full text is stored only where the licence allows (CC-BY, CC-BY-SA, MIT). Otherwise we store short excerpts and a link. See [`docs/provenance.csv`](docs/provenance.csv) and [`docs/licensing.md`](docs/licensing.md).
